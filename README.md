# spring-boot-journal-app

The Journal App is a secure Spring Boot–based RESTful application designed to allow users to create, manage, and organize personal journal entries. The system provides user authentication, role-based authorization, and supports CRUD operations on journal records.

It integrates MongoDB for flexible document storage, implements JWT and OAuth2 for secure authentication, Redis for caching frequently accessed data, and supports external API integrations such as email notifications and sentiment analysis. The application also includes scheduled background tasks, logging, validation, and automated testing to ensure reliability, scalability, and production readiness.
